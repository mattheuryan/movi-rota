# 🎬 Movie Rota
### Aplicativo de mobilidade e transporte corporativo

## 📌 Sobre o projeto

O Movie Rota é um aplicativo desenvolvido com o objetivo de facilitar a gestão do transporte corporativo, conectando motoristas e colaboradores por meio de uma plataforma mobile.

## 🎯 Objetivo
Criar uma solução tecnológica que facilite o gerenciamento de rotas, o acompanhamento de deslocamentos e a comunicação entre motoristas e colaboradores.

## ⚙️ Funcionalidades
- Área do motorista.
- Área do colaborador.
- Gerenciamento de informações.
- Acompanhamento de rotas.
- Recursos de segurança.

*Funcionalidades em desenvolvimento.*

## 💻 Tecnologias
- React Native
- Expo
- TypeScript
- Firebase
